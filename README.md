# 💊 Pharmacy Sales & Profitability Analytics Dashboard

## 📌 Overview

This Power BI report was developed for the **ZoomCharts Mini Challenge** hosted by **Onyx Data**. The dashboard analyzes pharmacy sales transactions across multiple European countries, providing insights into sales performance, profitability, product performance, and geographic trends.

The report is designed to help stakeholders:

* Monitor Revenue, Profit, Cost, and Margin performance
* Analyze sales trends over time
* Evaluate geographic performance across countries, regions, and pharmacies
* Identify top-performing product categories and brands
* Compare Generic vs Branded and Active vs Discontinued products
* Explore pharmacy performance through interactive drill-down analysis

---

## 🎯 Challenge Objectives

The dashboard addresses key business questions such as:

* How do revenue, profit, and margin evolve over time?
* Which countries and regions contribute the most to business performance?
* Which product categories and brands drive revenue and profitability?
* How do different pharmacy types and store sizes compare?
* What geographic patterns exist across the pharmacy network?

## ✨ Key Features

### Dynamic KPI Analysis

Users can switch between:

* Revenue
* Profit
* Cost

using Field Parameters for a fully interactive experience.

### Dynamic Titles & Subtitles

All major visuals automatically update titles and descriptions based on the selected KPI.

### Geographic Analysis

Interactive map and drill-down visuals allow exploration from:

Country → Region → City → Pharmacy

### Product Performance Analysis

Analyze products by:

* Category
* Brand
* Generic vs Branded
* Active vs Discontinued

### Product Image Integration

Integrated 200+ product images into the report using Python and the **icrawler** library.
